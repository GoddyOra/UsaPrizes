## Zero-budget research method (reference)

No paid keyword tools. Per page/cluster: check Google Autocomplete + "People Also Ask" for the
seed term, check Google Trends for seasonal spikes (jackpot news cycles), and inspect the current
top-ranking result to match content shape (list, table, FAQ). Once Phase 6 (Search Console) is
live, GSC's Performance report becomes the primary keyword-discovery tool — see Phase 9's weekly
loop in the main plan.
